# PassCo Interface — Replit-ready

A polished frontend MVP for the PassCo digital business passport concept.

## Included
- SME dashboard
- Digital business passport
- QR-code sharing modal
- Logistics marketplace
- Documents vault
- Analytics
- Responsive mobile layout

## Upload to Replit
1. Create a new Replit project using **Vite + React** or import this folder/ZIP.
2. Ensure all files are in the project root.
3. Open the Replit Shell and run:
   ```bash
   npm install
   npm run dev
   ```
4. Replit should expose the Vite webview automatically.

## Notes
This is a frontend prototype. Demo data is currently hard-coded.
The next production step is to connect authentication, a database, document storage, roles/permissions and API integrations.
